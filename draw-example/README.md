# Примеры `draw`

Файлы `draw-*` содержат ровно 64 сырых байта без префикса `draw ` и без перевода строки.

- `draw-bottom-layer`: во всех 64 столбиках установлен бит 0 (`0x01`).
- `draw-top-layer`: во всех 64 столбиках установлен бит 7 (`0x80`).
- `draw-front-diagonal`: на лицевой грани включено по одному светодиоду — диагональ от правого нижнего угла до левого верхнего. Используются байты с индексами `0, 8, 16, …, 56`, имеющие значения `01 02 04 08 10 20 40 80`.

Для отправки файла к нему нужно добавить ASCII-префикс `draw `, не изменяя сами 64 байта. Префикс и данные должны быть отправлены одной записью в уже открытый и настроенный последовательный порт.

Нельзя помещать бинарный файл в `$(cat ...)`: командная подстановка удаляет нулевые байты. Также нельзя отправлять префикс через `printf`, а данные отдельным процессом `cat`: прошивка не ждёт поступления недостающих байтов.
