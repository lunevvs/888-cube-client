# Вращающаяся диагональ

Серия состоит из 14 кадров `frame-*.bin` по 64 байта. Линия расположена на лицевой грани и вращается вокруг её центра. За 14 кадров она поворачивается на 180°, что образует полный визуальный цикл для линии без направления.

Первый кадр направлен от правого нижнего угла к левому верхнему. Кадры воспроизводятся в лексикографическом порядке имён.

Запуск с частотой 4 кадра/с:

```bash
python3 draw.py draw-series/rotating-diagonal
```

Другая частота:

```bash
python3 draw.py --fps 8 draw-series/rotating-diagonal
```

Воспроизвести три полных цикла и затем выключить все светодиоды:

```bash
python3 draw.py --cycles 3 draw-series/rotating-diagonal
```
