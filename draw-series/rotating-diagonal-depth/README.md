# Вращающаяся диагональ с движением в глубину

Серия содержит 28 кадров `frame-*.bin` по 64 байта. Диагональ вращается в вертикальной плоскости и через каждые два кадра перемещается на один слой в глубину куба.

Траектория глубины одного цикла:

```text
0, 0, 1, 1, 2, 2, …, 7, 7, 6, 6, …, 1, 1
```

Слой `0` — лицевая сторона, слой `7` — задняя. После последнего кадра следующий цикл начинается на слое `0`, поэтому движение возвращается к лицевой стороне без повторения крайнего слоя.

Запуск:

```bash
python3 draw.py draw-series/rotating-diagonal-depth
```

Воспроизвести два цикла и выключить куб:

```bash
python3 draw.py --cycles 2 draw-series/rotating-diagonal-depth
```
